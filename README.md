# Hugging Face Agents Course - Portfolio 🤖

Welcome to my repository for the Hugging Face Agents course! This repository contains the code and projects I've built to explore and develop advanced AI agents.

## 🚀 Projects Included

### 1. Gala Agent
A sophisticated agent implementation featuring:
- **GAIA (General AI Assistant)** integration and testing capabilities.
- **Supabase** backend for database management and agent memory.
- **Langfuse** for observability, prompt management, and tracing.
- Custom retrieval tools, document processing, and routing mechanisms.

### 2. Gatekeeper Agent
A specialized agent designed to manage and filter interactions or enforce policies.

### 3. Vision React Agent
An advanced ReAct (Reasoning and Acting) agent equipped with vision capabilities, allowing it to process and reason over images.
